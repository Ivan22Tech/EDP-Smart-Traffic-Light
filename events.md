
# Events Documentation

## Project: EDP Smart Traffic Light System

This project uses Event-Driven Programming (EDP) to simulate an
automatic traffic light system.

Events are generated by event producers, placed in a local event
queue, and processed by event handlers.

## 1. SYSTEM_START

**Producer:** Start System button

**Description:** Starts the traffic light system.

**Handler action:**
- Changes the traffic light to GREEN.
- Activates automatic timer scheduling.

## 2. TIMER_EXPIRED

**Producer:** Automatic timer using Tkinter after()

**Description:** Generated automatically when the configured
traffic light interval expires.

**Handler action:**
- GREEN changes to YELLOW.
- YELLOW changes to RED.
- RED changes to GREEN.
- If a pedestrian is waiting, crossing is activated at RED.
- If pedestrian crossing is active, it finishes and GREEN returns.
- If emergency priority is active, it is cleared and GREEN returns.

## 3. PEDESTRIAN_REQUEST

**Producer:** Pedestrian Request button

**Description:** Represents a pedestrian requesting permission
to cross the road.

**Handler action:**
- Sets pedestrian_waiting to True.
- The request waits until the traffic light reaches RED.
- Pedestrian crossing is then activated.

## 4. EMERGENCY_DETECTED

**Producer:** Emergency Vehicle button

**Description:** Represents an emergency vehicle approaching
the intersection.

**Handler action:**
- Activates emergency priority.
- Changes the traffic light immediately to RED.
- The next TIMER_EXPIRED event clears emergency priority.

## 5. Event Processing Flow

1. An event producer generates an event.
2. The event is published to the local event queue.
3. The event handler processes the event.
4. The traffic light state is updated.
5. The graphical interface displays the new state.

## 6. Event Queue Type

The application uses Python's queue.Queue.

The queue is local and does not require a network connection.

## 7. Automatic Event Generation

The Tkinter after() function schedules TIMER_EXPIRED events.

It allows automatic traffic light changes without blocking
the graphical interface.
