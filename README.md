# Smart Traffic Light System

### Event-Driven Programming (EDP) Project

## Description

A Python-based Smart Traffic Light System that
simulates an intelligent traffic intersection
using Event-Driven Programming.

## Features

- Local event queue
- Traffic light state management
- Pedestrian crossing requests
- Emergency vehicle priority
- Event-driven architecture

## Requirements

- Python 3.x

No external Python libraries are required.

## How to Run

1. Clone the repository:

   git clone YOUR_REPOSITORY_URL

2. Open the project directory:

   cd EDP-Smart-Traffic-Light

3. Run the application:

   python main.py

## Project Structure

- main.py: Main application
- event_queue.py: Local event queue
- event_producers.py: Event producers
- event_handlers.py: Event handlers
- traffic_light.py: Traffic light controller
- events.md: Event documentation
- architecture.md: System architecture

## Technologies

- Python
- Event-Driven Programming
- FIFO Event Queue
